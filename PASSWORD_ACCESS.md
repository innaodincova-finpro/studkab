# Вход, облако и восстановление доступа

Два режима хранения: без входа на устройстве; после входа — облако с отдельной локальной копией аккаунта. Два способа входа: Google и пароль приложения. Первый вход без Google — персональное приглашение из реестра. Пароль общий с «Точкой дня», данные приложений разделены.

## Синхронизация
При открытии сравниваются данные устройства, облако и последняя подтверждённая версия этого аккаунта на этом устройстве. Если изменена одна сторона, перенос выполняется автоматически. Если изменены обе стороны или нет основания выбрать версию, приложение спрашивает явно. Отложенный выбор ничего не заменяет и не разрешает автоматическую перезапись.

Перед явной заменой локальная и облачная версии сохраняются отдельно на устройстве, без ключей нейросетей. В «Копия данных → Копии перед заменой» доступен выбор файла. Если копию создать невозможно, замена отменяется. Это локальные страховочные копии последнего выбора, а не долговременный серверный архив.

Статус различает чтение из облака, подтверждённую отправку изменений, ожидание отправки, незавершённый выбор и ошибку. Время чтения не выдаётся за время записи.

## Восстановление без SMTP
Исполнитель входит в реестр → Ещё → Доступ студентов → Восстановить доступ. До создания ссылки лично подтверждает владельца аккаунта через ранее известный канал связи. Указывает его почту, отмечает подтверждение и получает одноразовую ссылку. Передаёт её лично владельцу. Получатель открывает ссылку в браузере без активного входа в кабинет, задаёт пароль сам.

Сервер проверяет подтверждённый аккаунт исполнителя по закрытой конфигурации. Приглашение никогда не сбрасывает существующий аккаунт. Восстановление не создаёт отсутствующего пользователя. Ссылка предоставляет доступ к общему аккаунту; нельзя публиковать, передавать третьим лицам или создавать без проверки личности.

Самостоятельное восстановление письмом и автоматическая почтовая доставка остаются отключёнными: SMTP не настроен. Переписка через Telegram-бота не реализована; его текущая роль — доставка заявок исполнителю.

# AI-посредник: исправление подготовки черновика

`ai-proxy.mjs` — полный файл для существующего Cloudflare Worker `calm-bird-dae8`.
Основа: код действующего посредника, предоставленный владельцем 9 сентября 2026 года.
Markdown-экранирование из сообщения снято; URL восстановлены как обычные строки.

## Изменения

- Текст `system` и `user` больше не обрезается на 40 000 символах. Суммарный предел 180 000 символов согласован с редактором. Превышение возвращает `CONTEXT_TOO_BIG` до обращения к платной модели.
- Размер входящего потока ограничен 1 200 000 байт, включая кириллицу и JSON. Предел контролируется при чтении потока.
- Незавершённые ответы отклоняются (`INCOMPLETE:<provider>`). Для DeepSeek/OpenAI/GigaChat принимается `finish_reason=stop`, для Anthropic — `end_turn`/`stop_sequence`, для Yandex — `ALTERNATIVE_STATUS_FINAL`.
- Запрос к поставщику ограничен тремя минутами. Автоматических повторных платных запросов нет.
- Произвольные тексты ошибок поставщика не возвращаются в браузер.
- Секреты и список поставщиков сохранены; новые аккаунты и ключи не требуются. Модели из прежнего списка не заменялись; доступность других поставщиков вживую не подтверждена.

## Проверка и выпуск

`npm test` включает тесты посредника с имитацией ответов поставщика, без ключей и расходов.
Реальные запросы выполняются отдельно на учебных данных. Успешные тесты не означают публикацию.

Для существующей ручной установки Cloudflare: открыть Edit code, заменить содержимое проверенным файлом целиком и Deploy. Секреты не переносить в файл и не менять. Перед заменой сохранить номер текущей версии в Deployments; на предоставленном снимке активна `28d42dab`. При ошибке вернуть предыдущую версию через Cloudflare Deployments.

Порядок выпуска: проверенный посредник → проверка ответа DeepSeek → реестр с новым редактором → проверка полного Word → серверная проверка результата. Публикация файла в GitHub сама по себе не обновляет Cloudflare Worker.

## Изолированная проверка

Обычный Vite-предпросмотр имеет `connect-src 'self'` и не обращается во внешние сервисы. Это было причиной отказа живой генерации, а не настройка ALLOWED_ORIGIN в Cloudflare.
Для явно запрошенной проверки с реальным DeepSeek используется `reestr.html?ai-qa=1`: разрешён только существующий адрес посредника. Подменённое облачное хранилище остаётся изолированным. Секрет вводится в настройках браузера; в репозитории отсутствует.

Ограничения: rate limit в памяти Worker остаётся приблизительным, не глобальной квотой. Успешный finish_reason подтверждает завершение ответа поставщиком, но не достоверность содержания. Факты, расчёты и источники требуют проверки исполнителем.

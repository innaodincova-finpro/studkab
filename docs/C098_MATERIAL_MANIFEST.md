# C098 — обязательный состав материалов

## Причина

Проверки заполненности паспорта и его связи с версией исходников не доказывают
полноту исходников. Утверждение текста требований не должно подменять проверку
наличия материалов, без которых нельзя выполнить конкретное задание.

## Правило

Каждая новая утверждаемая версия паспорта содержит перечень материалов с
основанием его состава. Исполнитель определяет перечень по заданию. Каждый
обязательный пункт связан с фактическими материалами этой заявки: актуальным
вложением, ответом студента либо непустым полем исходной заявки из разрешённого
списка. Для неприменимого пункта требуется объяснение. Пустая галочка, имя файла
в свободном тексте и файл другой заявки доказательствами не являются.

Это контроль наличия выбранных доказательств, а не автоматическое понимание
содержания методички. Правильность и полнота самого перечня остаются предметом
проверки исполнителя. Объединённый файл допустим, если действительно содержит
необходимые материалы. Универсального количества файлов для всех работ нет.

После изменения материалов необходимо повторно проверить состав и утвердить
актуальную версию паспорта. Исторические паспорта и результаты сохраняются.
Старый паспорт без перечня не является разрешением на новую подготовку.

## Приёмочные сценарии

| Сценарий | Ожидаемый результат |
|---|---|
| Паспорт без перечня | Утверждение и новая подготовка запрещены |
| Обязательный баланс без привязки | Назван недостающий пункт, переход запрещён |
| Указан файл другой заявки | Сервер отклоняет привязку |
| Указан заменённый файл | Сервер отклоняет неактуальное доказательство |
| Пустое поле или ответ без текста | Пункт не считается обеспеченным |
| Необязательный пункт без объяснения | Проверка не пройдена |
| Все пункты обеспечены актуальными материалами | Утверждение разрешено при остальных выполненных условиях |
| Материалы изменены после проверки | Нужна новая проверка; старое разрешение не используется |
| Прямой API-вызов в обход интерфейса | Серверные ограничения сохраняются |
| Ручное прикрепление Word вместо генерации | Не обходит требования к комплекту |

## Статус

Реализация и проверки выполняются. Этот документ не подтверждает установку
в рабочей среде, восстановление входа или завершение полного маршрута двух ролей.

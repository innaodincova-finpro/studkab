# C102 — независимая проверка локального изменения

23.09.2026. Проверены backend, SQL, ограниченный scanner и интерфейс журнала
качества. Это проверка локального кода; CI, установка и сквозная приёмка ещё
не подтверждены. Производственные данные и платные сервисы не использовались.

## Исправленные находки

1. Источники без извлечённого текста исключались из отчёта, позволяя получить
   положительный результат по неполному загруженному корпусу. Теперь учитываются
   все текущие вложения категории `sources`, сохраняются их имена и хеши;
   положительный результат требует `usableSources === providedSources > 0`
   и отсутствия усечения. SQL отдельно блокирует пустое извлечение.
2. Новая запись evidence делала прежнюю итоговую проверку устаревшей, но интерфейс
   не позволял проверить ту же Word-версию повторно. Теперь сервер возвращает
   `prepared / quality_review_stale`, интерфейс создаёт новый идентификатор
   проверки и снимает подтверждение. История остаётся доступной.
3. Формулировка «проверено» завышала фактическое покрытие при остановке scanner
   по лимиту. Теперь показан объём, включённый в обработку, и явное предупреждение
   о неподтверждённой полноте; положительный результат закрыт.

Новых блокеров в финальном просмотренном срезе не обнаружено. Проверены привязки
request/version/recipient/passport/file hash/document hash/source fingerprint,
неизменяемость журнала, связь итоговой проверки с конкретными evidence IDs,
повторная проверка после изменения evidence и сохранение исторического чтения.
SQL использует явный отказ при неизвестном disposition. C099 не становится
обычной выдачей и не получает отметку завершённого качества.

## Ограничения

Внутреннее сравнение ищет ограниченные последовательности токенов в основном
извлечённом тексте Word и предоставленных фрагментах источников. Это не поиск
по Интернету, не семантический поиск и не официальный процент оригинальности.
Изображения, колонтитулы и сноски не входят в сравнение. Наличие извлечённого
фрагмента не доказывает полноту извлечения исходного файла. Содержание, числа,
смысл цитирования и качество аргументации требуют отдельной предметной оценки.

Внешний PDF загружает исполнитель: он подтверждает систему, порог из точного
пункта паспорта и соответствие отчёта проверяемому Word. Проверки формата,
хеша и заявленных привязок не доказывают подлинность PDF и не распознают любую
подделку. Настоящая внешняя проверка этим локальным тестом не выполнена;
платные проверки синтетических материалов запрещены.

Локальный пример на синтетическом Word №2: SHA256
`5eda2a57275b5026b25313cf88e5ba36529b59fba9bbcabf81fda0319263953c`,
1319 токенов документа, 128 токенов предоставленного фрагмента P2, 0 совпадений,
`truncated=false`, `status=manual`, `officialOriginality=false`. Это пример
ограниченного сравнения, не production scan, внешний отчёт или оценка «пройдено».
Текст работы и частные входные файлы в репозиторий не включены.

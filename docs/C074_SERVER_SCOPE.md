# C-074: серверная защита явного минимума источников

Основание: TASK R5/R7/R8/R9, расхождение исходного задания UAT-MGMT-01 и паспорта.
Перед утверждением, запуском генерации и новой проверкой/передачей сверяются
серверные вложения assignment/methodology с пунктами паспорта. Узкий распознаватель
обрабатывает только явные числовые минимумы источников; отсутствие совпадений
не является приёмкой. Summary «согласовано» не отменяет исходник.
Альтернатива автоматического исправления паспорта отклонена: не менять требования
и данные без основания. Чтение ранее переданных работ сохраняется.
Это предварительная Edge-проверка, не атомарная SQL-гарантия: одновременная загрузка
материалов между чтением и RPC остаётся границей. Для атомарной гарантии потребуется
отдельная миграция и общий протокол блокировки загрузки материалов/утверждения/
старта/передачи. Текущие SQL-защиты версии и получателя сохраняются.
Проверки: конфликт 10/5, соседняя строка «Список источников / Не менее 10 позиций»,
произвольные идентификаторы пунктов, отсутствие document, ошибки чтения, отрицательные
примеры. Откат: вернуть Edge-код, исходные данные и история не изменяются.

После независимой проверки: квалифицированные подмножества («из них», «в том числе»,
иностранные/электронные источники, источники за последние годы) не используются как
общий минимум. Нераспознанные условия остаются предметом ручной проверки. Отсутствие
массива items или текста сохранённого пункта — ошибка чтения, допуск запрещён.
Подготовка/сохранение версии Word не блокируется этой проверкой: она нужна для
исправления документа; утверждение проверки и передача блокируются.
Публикация требует обеих функций: studkab-requests и studkab-generation-api.
Автоматический workflow deploy-studkab-requests.yml публикует только первую;
старый scripts/c051-install.mjs содержит публикацию второй вместе с другими действиями
и не должен запускаться целиком для этого изменения. Supabase CLI собирает импорты
_shared/source-minimum.mjs транзитивно; при ручной сборке необходимо включить этот файл.

# Общая концепция интерфейса STUDKAB

UI-CONCEPT-01. Прямое требование владельца 09.10.2026 для всего приложения,
обеих ролей и будущих изменений. Это правило, не уже установленная версия.

Рабочий экран отвечает: что сейчас с заявкой; что сделать; какой результат
получен; что делать дальше. Основное действие соответствует серверному состоянию.
Успех показывается после подтверждённого результата.

Не размещать инженерные абзацы о протоколах, резервах, лимитах и обработчиках.
Краткая причина ограничения, предельная стоимость и согласование оплаты остаются,
если определяют решение. Подробности — в документации и отдельном разделе
подключений и расходов. Комментарий нейросети о работе — предметный результат.

Автоматически: все материалы → выбранная нейросеть → работа с комментарием
в заявке → проверка исполнителем → передача студенту. Без внутреннего OCR допуска.

При недоступности автоматики: скачать полный комплект → открыть чат и прикрепить
комплект → вернуть работу с комментарием → проверить → передать.
Открытие ссылки не означает отправку файлов.

| Состояние | Основное действие |
|---|---|
| Автоматика доступна | Подготовить автоматически |
| Нет подключения | Открыть подключения |
| Средств поставщика недостаточно | Открыть оплату |
| Предел приложения достигнут | Открыть расходы |
| Работа готовится | Посмотреть состояние |
| Работа и комментарий сохранены | Проверить результат |
| Ответ получен, файл сохраняется | Посмотреть состояние |
| Нужны уточнения | Посмотреть вопросы |
| Способ не принимает весь комплект | Скачать комплект для чата |

Таблица — контракт будущего согласованного макета. Для исполнителя без права
менять бюджет — доступное действие и обращение к владельцу. Сохранять чат.

Приёмка: серверные статусы; действие и видимый результат каждой кнопки;
ссылки на конкретные страницы; область нажатия минимум 44 px; отсутствие
перекрытия навигацией; прокрутка и закрытие окон; ошибки, ожидание, отсутствие
денег/подключения, повторный клик и восстановление после перезагрузки.
Технические объяснения не возвращаются при новых правках. Документация, макет,
тесты, установка и пользовательская приёмка отмечаются раздельно.

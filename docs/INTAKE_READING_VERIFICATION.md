  повтор из кэша без чтения оригинала, активная/истёкшая аренда, устаревший результат,

## Ограничения и остаток

Все файлы/расходы технические; API ИИ не вызывался, production не изменялся.
Чтение сохраняет источник и ограничения, не утверждает требования и не пересчитывает
финансовую работу. PDF с любыми изображениями/графикой консервативно заблокирован;
OCR, распознавание диаграмм и доказательство полноты сложной верстки не реализованы.
Общие формулы Excel сохраняются с индексом/диапазоном, без их самостоятельного
развёртывания/пересчёта. Поля/формулы Word имеют непроверенный сохранённый результат.
При принудительной остановке Edge следующий запрос после истечения аренды может
повторить чтение; фоновый автономный анализ ещё не внедрён.

Полный CI нового head, рабочая установка и пользовательская приёмка — отдельные
статусы. Шаг 4 — анализ содержания/распределение и проверка кандидатов с точными
источниками и серверным пределом расходов; шаги 5–8 — подтверждение, отправка,
совместимость, выпуск и сквозная приёмка. Старый extract.ts не изменён.

# STUDKAB — ROUTE-03: маршрут заявки без автоматического чтения материалов

Дата согласования: 05.10.2026. Решение владельца: «Да» на предложение «путь один, автоматика остаётся необязательной кнопкой».
Статус: план согласован; реализация не начата. ROUTE-03 заменяет порядок C → H плана ROUTE-02.

## Обязательное правило владельца — 02.10.2026

Прямое поручение владельца: «Я тебе запрещаю выполнять задачи по своему усмотрению, запиши это везде где нужно».

- Выполнять только поручения владельца в рамках утверждённого TASK.md и плана ROUTE-03; не придумывать дополнительные задачи.
- Не менять самостоятельно цель, объём, последовательность этапов, приоритеты, обязательные проверки и критерии завершения. Изменения этих условий сначала явно согласовать с владельцем.
- Правки интерфейса согласовываются картинками «сейчас / станет» до написания кода.

## 1. Основание

04.10.2026 по одной студентке выполнено 8 работ по 7 дисциплинам (математика, история России,
правоведение — практические и лабораторная, русский язык, основы российской государственности,
физическая культура — реферат, иностранный язык). Материалы: PDF с формулами-картинками,
снимки экрана страниц учебника, повреждённый файл с сайта вуза, текст, вставленный вручную.
Автоматическое чтение ROUTE-02 такие материалы останавливает; снимки экрана к загрузке не допускаются.
Все работы выполнены исполнителем вручную. В рабочей базе ни одна заявка не дошла до утверждения
требований, подготовки или выдачи (проверено 04.10.2026).

## 2. Согласованный результат

Программа ведёт маршрут заявки и не читает материалы. Материалы читает и выполняет исполнитель.
Путь один для обеих ролей.

Студент: Задание → Вопросы → В работе → Готово → Сдача.
Исполнитель: Получена → Вопросы → В работе → Передана → Сдана.

1. Студент заполняет форму: вид работы, дисциплина, вуз, кафедра, направление подготовки,
   форма обучения, курс и группа, ФИО, преподаватель, срок, пожелания.
2. Материалы — файлами любого вида (Word, PDF, Excel, фото, снимки экрана) и/или ссылкой на папку
   в облаке (Яндекс Диск, Google Диск, Облако Mail.ru). Отправка не зависит от чтения файлов.
3. Заявке присваивается номер; в реестре карточка со сведениями, файлами и ссылкой; уведомление исполнителю.
4. По ссылке программа проверяет, что она открывается без входа, и сохраняет копию материалов в заявке
   (студент может удалить файлы или закрыть доступ). Если копия невозможна — отметка в карточке.
5. Исполнитель: «Скачать всё» (материалы и сведения одним архивом), «Задать вопрос студенту»
   (существующее окно вопросов), «Взять в работу», «Передать студенту» с прикреплением готового файла.
6. Студенту — уведомление и файл в кабинете; «Я сдал работу»; «Вернули на доработку» с замечаниями
   и файлами — заявка проходит круг ещё раз, число возвратов видно.
7. Автоматика ROUTE-02 (чтение, изучение комплекта, платный разбор, утверждение требований,
   автоматическая подготовка) не удаляется и не развивается; доступна исполнителю по желанию
   кнопкой «Изучить автоматически» и не блокирует маршрут. Политика платного разбора остаётся выключенной.

## 3. Этапы (порядок определён исполнителем)

| Этап | Содержание | Зависит от |
|---|---|---|
| R3-A | Форма заявки (сведения для титульного листа), файлы любого вида, поле ссылки, отправка без чтения; карточка в реестре со сведениями | Утверждение картинок «сейчас / станет» |

| R3-G | Общая проверка (CI) и приёмка двумя ролями на реальной заявке | все |

## 4. Что сохраняется

Защита данных, доступ только своему студенту, служебные функции базы только service_role,
изоляция аккаунтов, история и нумерация заявок, существующее окно вопросов (UX-02a),
бюджеты и выключенная политика платного разбора.

Пункты C–H ROUTE-02 закрываются этим планом. Сделанное по ROUTE-02 (приём, окно вопросов,
изучение комплекта, стенд) установлено и остаётся в работе как необязательный помощник.

# C177-P6 — покрытие явных условий текущих материалов

TASK R5/R8/R14. Общий серверный модуль используется при построении и утверждении паспорта, перед запуском проверки точного Word и при приёме её отчёта. Явное условие задания/методички считается покрытым только обязательным проверенным пунктом с дословным текстом и ссылкой на тот же текущий исходный файл. Одинаковые условия разных файлов сохраняют отдельные привязки. Неполное покрытие блокирует запуск до чтения бюджета и постановки в очередь; сервер не принимает отчёт с пропущенным условием.

Интерфейс объясняет необходимость обновить паспорт. В инструкции помощнику показанный расчёт больше не считается достаточным основанием пропустить его проверку. Фиксированного учебного комплекта или числа формул нет.

Это консервативное извлечение явных условий, а не полный смысловой разбор. Второй предметный проход, полный независимый пересчёт, источники, страницы Word и сквозная производственная приёмка остаются открытыми. Схема, исторические данные, провайдер и лимиты расходов не меняются; платные вызовы не выполнялись. Откат — revert кода P6 с сохранением истории.

Локально: 54 теста API и 25 тестов паспорта прошли. Проверены пропуск требования, разные источники с одинаковым условием, неверная привязка, необязательный/непроверенный пункт, замена материала и отказ до резервирования. Общий локальный набор в среде с доступным запуском дочерних процессов прошёл: 15 предварительных и 550 основных тестов. Ограниченная среда блокировала часть SQL-проверок с EPERM. Браузерные проверки и CI этой версии ещё не выполнялись. Публикация исходного кода в GitHub заблокирована автоматической проверкой разрешений; обход не выполнялся. Изменение подготовлено в draft PR, в рабочую среду не установлено.

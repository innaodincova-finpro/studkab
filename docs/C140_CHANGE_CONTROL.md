# C140 — понятное действие для уже переданной заявки

TASK R3/R9/R10, 26.09.2026. В опубликованном кабинете заявка №1 уже передана и находится на этапе проверки Word, но её карточка всё ещё предлагает «Отправить заявку». При открытии та же кнопка повторяется в форме, а ошибка изменения ошибочно называет переданную заявку неопубликованным черновиком.

Решение: при наличии серверного ID и отметки передачи показывать «Условия заявки» и «Сохранить изменения заявки», объяснять предел изменений до начала подготовки и корректно сообщать об отказе сохранения. Для новой и ещё не опубликованной заявки сохранить прежние подписи, проверку полей и серверный маршрут. Отдельно подтвердить, что опубликованная форма разрешает описание задачи вместо файла задания и не требует вымышленных файлов данных или источников; обязательность дальнейшего комплекта определяет исполнитель по заданию в паспорте.

Данные, права, вложения, Telegram, серверные функции и выдача Word не меняются. Платных проверок нет. Проверка: адресный браузерный сценарий двух состояний, Node-проверки карточки и валидации, CI; затем чтение опубликованной карточки. Откат: вернуть один `index.html` и его подписи; миграции не нужны. Альтернатива оставлять повторную команду «Отправить» признана вводящей студента в заблуждение.

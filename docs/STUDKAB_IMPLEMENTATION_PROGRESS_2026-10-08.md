## Подтверждённое поведение

Выбор помощника не означает запуск. Подготовленный комплект, очередь, подтверждённая обработка, возвращённый файл, проверка и передача различаются. Потерянное подтверждение отправки восстанавливается по той же операции; повторный клик не создаёт вторую задачу. Неопределённый платный результат не запускается повторно и не освобождает резерв без доказательств. Сбой сохранения Word восстанавливает уже полученный ответ без нового обращения к модели. Старый файл после возврата на доработку не становится новым результатом.

Комплект включает доступные требования, исходные файлы с проверенными байтами и хешами, сведения о работе, циклы материалов и ответы. Тест проходит через настоящий SQL движок PGlite и создаёт настоящий Word; ответ модели в нём подставной. Это проверка механизма, а не производственная приёмка помощника. Отдельные десять конкурентных сценариев для native PostgreSQL включены в CI.

Перед платным шагом сервер фиксирует сумму, версию и полный комплект; UI подтверждает именно эту сумму и ту же операцию. Глобальная доступность подключения не подменяет проверку конкретной заявки. Автоматическая подготовка по умолчанию отключена, текущие лимиты и денежные записи не менялись.

Уведомление хранит отдельную квитанцию канала; она не доказывает прочтение. Повтор касается только уведомления. Неопределённое подтверждение доставки не повторяется автоматически. Telegram-ссылка одноразовая, ограниченная по сроку и связанна с вошедшим пользователем; создание ссылки не означает подключение. SMTP использует только существующие серверные настройки, без создания нового сервиса. Сообщения не включают комплект документов или секреты.

# C154 — сохранённые замечания ИИ, 28.09.2026

R8/R13. Ответ первого ИИ прохода C152 уже сохраняется в неизменяемой части задачи, но до C154 виден только после ручного восстановления. Сервер читает задачу исполнителя по актуальной версии Word, SHA-256 и утверждённому паспорту, проверяет JSON, все 16 кодов, место, основание и наблюдение. Карточка автоматически показывает сохранённые замечания и непроверенные критерии. Модель не отмечает прохождение, не выдаёт документ и не выступает от имени исполнителя.

Альтернатива — записать вывод модели как `studkab_result_reviews` с `reviewer_id` исполнителя — исказила бы авторство. Новых платных вызовов, миграций и изменения исторических данных нет. Проверка: `tests/generation-api.test.mjs`, `tests/browser/quality-evidence.spec.cjs`, CI и затем рабочая сверка. Откат: прежний Edge и интерфейс; сохранённые ответы задач остаются доступными.

Факт локально: адресные тесты API 39/39; browser в данном окружении не стартовал без Chromium; полный Node-набор прервался из-за SIGKILL в SQL-сценарии. CI, публикация и проверка на реальной работе фиксируются отдельно.

# C099 Отдельная тестовая передача Word

## Основание

Пользователь согласовал техническую передачу синтетических данных без платной
проверки оригинальности. Это не содержательная приёмка и не выдача готовой работы.

## Поведение

Тестовый маршрут доступен только для явно разрешённой сервером пары заявка/получатель.
Исполнитель подтверждает передачу тестового файла с предупреждением
«Тестовый файл — проверка качества не завершена».
Кабинет показывает отдельный файл с тем же предупреждением; обычный статус и
результат не заменяются. Незавершённые проверки остаются незавершёнными.
Никаких pass/not_applicable вместо фактического результата не записывается.

Допуск нельзя создать названием заявки, клиентским флагом или произвольным API
параметром. Он управляется отдельно от публичных действий приложения.
Отзыв допуска, смена получателя, версии или паспорта запрещают дальнейшее чтение.
Уже скачанную на устройство копию технически отозвать невозможно.

## Установка и откат

Установка: SQL-миграция → Edge → интерфейс. Разрешение конкретного синтетического
случая выдаётся отдельно после проверки рабочей версии; миграция никому автоматически
не выдаёт тестовый доступ. Обычный контроль качества сохраняется.
Откат: отозвать тестовые допуски и отключить UI/API тестовой передачи, сохранить
историю. Не удалять версии Word, исходные данные и обычные передачи.

## Приёмка

Проверить отсутствие допуска, чужого получателя, неисполнительскую роль, отзыв,
смену паспорта/материалов/версии, несовпадение хеша, повтор и конфликт операции.
Проверить отдельную карточку студента, постоянное предупреждение после обновления,
скачивание точных байтов и неизменность обычного результата/статуса.
Локальные синтетические проверки не заменяют проверку опубликованной версии
двумя авторизованными ролями.

# C155 — исправление чтения привязки ИИ проверки, 28.09.2026

R8/R13. Проверка C154 выявила ошибку при чтении сохранённой задачи: `studkab_gen_start` кладёт вход в `snapshot.input`, тогда как `status` и история ИИ читали `snapshot.review_target`. По этой причине ответ модели мог существовать, но карточка не могла подтвердить его версию.

Исправлены оба чтения и фильтр PostgREST на `snapshot->input->review_target`. Альтернатива — дублировать поле в новой записи задачи — не исправляет уже сохранённые ответы и меняет контракт хранения. Миграция и платный запуск не нужны. Проверка: тест с реальным конвертом `snapshot.input`, 40/40 адресных тестов, CI, затем повторная установка Edge и проверка версии. Откат: прежняя версия Edge, сохранённые задачи не изменяются. Фактических задач ИИ в рабочей БД на момент проверки нет (счётчик 0); ответ реальной модели не заявляется.

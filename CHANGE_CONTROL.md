## C-057 — контекст раздела не должен исчерпывать лимит всей работы, 2026-09-18

план, результаты, права, данные и денежные пределы не меняются. Проверки: отсутствие

Edge Functions и production не публикуются, платных вызовов нет. Откат — отмена
локального commit/PR; после публикации — возврат прежних версий обеих функций.

не удаляются. Объединение и публикация в данный этап не входят.

## C-071 — сохранить проверку отдельно от передачи, 2026-09-19

R3/R8/R9. Пользователь поручил следующий пакет после публикации C-070 (PR #111,
main bc079269). Факт: results-ui.js одним кликом вызывает prepare/review/deliver,
а подтверждение теряется после закрытия окна. Решение: две явные операции,
читающее действие result-review-state только для исполнителя, восстановление
точных байтов/протокола из существующих неизменяемых таблиц. JSON документа
дополняется reviewContext с отпечатком исходных данных и идентификатором паспорта;
сервер сверяет актуальный утверждённый паспорт при подготовке, чтении и передаче.
Старые документы остаются доступны студентам; старое одобрение без контекста не
переиспользуется новым интерфейсом. Новые таблицы и расширение прав не нужны.

Стабильный deliveryId равен versionId, повтор после обрыва не создаёт новую
выдачу. При неопределённом состоянии сервер недоступен — передача заблокирована.
Изменения документа/требований/получателя/аккаунта аннулируют допуск. Сохранение
проверки никогда не вызывает deliver. Данные не удаляются; AI и платные вызовы
не нужны. Проверки: серверные права/привязка/устаревание и браузерное закрытие,
перезагрузка, обрывы ответов, редактирование и отдельный клик передачи.
Уточнение: для защиты от одновременной смены паспорта добавлена миграция
20260919124300 (создана CLI): расширен существующий INSERT-триггер под блокировкой
заявки. Таблицы/права/данные не меняются.
Развёртывание: сначала миграция, затем совместимый Edge endpoint, затем frontend; до установки
endpoint новый клиент закрывает передачу при ошибке проверки состояния.
Откат: вернуть frontend; additive endpoint можно оставить, неизменяемая история
сохраняется. Реальная установка — после проверки пакета.
Capability marker studkab_result_context_version() устанавливается атомарно с
триггером; новый сервер проверяет его до допуска нового маршрута. Это читающая
функция только для service_role; пользовательские права не расширяются.
Порядок установки и откат уточнены в docs/C071_DEPLOYMENT.md.

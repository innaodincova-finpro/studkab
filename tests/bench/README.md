# Учебный стенд проверки комплекта (BENCH-01)

Назначение: измерять качество проверки комплекта документов на наборе учебных комплектов, а не на одной заявке.

Состав: каталог `kits/` — учебные комплекты. Буква — основа (A — мотивация персонала, B — финансовый анализ, C — статистика), цифра 0 — полный комплект без дефектов, остальные — по одному заложенному дефекту. Поле `expected` описывает дефект и ключевые слова для подсчёта; модели оно не передаётся.

Как работает: функция `studkab-kit-bench` получает номер комплекта, коммит и способ проверки, читает комплект из репозитория по этому коммиту, резервирует сумму в отдельном лимите стенда и только затем обращается к модели. Результат и подсчёт сохраняются в `studkab_kit_bench_runs`.

Ограничения: стенд не связан с заявками, студентами и общим журналом расходов генерации; по умолчанию выключен; лимит — не более $1 (разрешение владельца 03.10.2026).

Мерило качества (разрешение владельца 03.10.2026): найдено не меньше 9 из 10 заложенных дефектов и в среднем не больше одного лишнего вопроса на комплект. Подсчёт по ключевым словам проверяется чтением ответов вручную.
